# Windows 图形启动与局域网联机

## Intent

用户已批准上一轮方案并要求直接实现：同一个 Windows EXE 提供本机单机、创建局域网和加入局域网三种模式，自动处理连接配置与退出还原，保留原版 Zwift 登录及地图选择流程。

## Boundaries & Constraints

沿用原服务端及玩家存储，保持源码启动兼容；用户原有配置和已有工作流修改保留。系统变更只由隐藏提权辅助进程执行，游戏仍由原用户启动。加入模式不启动本地服务，也不检查本地服务监听端口。服务器模式支持未安装 Zwift 的电脑；仅选择本机骑行时检查安装。运行中禁止切换模式。窗口退出等待恢复完成；强制结束仍使用独立恢复进程。IP 首期限定明确的 IPv4，记住用户选择和上次地址。TCP 检测不能证明 UDP 骑行同步，说明验证范围。

## I/O & Edge-Case Matrix

| 场景 | 行为 |
| --- | --- |
| 单机 | 本地服务准备好后配置并启动原 Launcher；退出恢复本次系统变更 |
| 创建局域网 | 显示网卡/IP 选择和复制地址，本机骑行可选；启用多人并公布所选 IP |
| 加入局域网 | 校验地址和远端服务，临时 hosts 指向远端，启动 Launcher，保持辅助进程 |
| 无效 IP/服务器未开启 | 明确显示失败，不启动游戏，不留下系统改动 |
| 无 Zwift | 骑行模式提示安装；纯服务器允许启动 |
| UAC 拒绝/端口占用/子进程退出 | 界面显示具体失败，回滚当前会话，不丢失日志 |
| 窗口关闭/强制结束 | 先停止本次服务进程，再还原 hosts/证书/本次新增防火墙规则 |
| 已有配置/他人并发修改 | 只撤销本次所有权明确的变更，冲突保留恢复记录 |

## Code Map

- `windows_launcher.py`：现有入口、UAC 通信、崩溃恢复和 Launcher 启动。
- `windows_client_config.py`：hosts/证书事务及持久化恢复记录。
- `standalone.py`、`zwift_offline.py`：服务运行入口、就绪回调和启动参数来源。
- `standalone.spec`：当前排除 Tkinter，控制台模式。

## Tasks & Acceptance

- [x] `windows_network.py`：IPv4 验证、Windows 网卡枚举、远端 TCP 探测、会话专属防火墙规则。
- [x] `windows_client_config.py`：目标 IP 参数、纯服务器会话及防火墙记录和恢复，向后兼容旧记录。
- [x] `windows_launcher.py`、`windows_gui.py`、`windows_session.py`：Tkinter 主界面、后台操作、原用户服务子进程、就绪/停止通信、三模式控制及设置持久化。
- [x] `zwift_offline.py`：仅对 GUI 子进程提供环境覆盖多人模式和公布 IP，避免切换单机删除原多人配置。
- [x] `standalone.spec`：包含 Tkinter，图形入口，后台进程隐藏窗口，数据白名单继续生效。
- [x] `tests/`：覆盖连接/服务分支、远端 hosts 恢复、纯服务器、防火墙回滚、子进程断开、GUI 状态和已有启动回归。

验收：Given 多台同网段电脑，When 一台创建局域网且其他电脑加入同一 IP，Then 共用同一多人服务并各自登录；Given 创建者未安装 Zwift，When 关闭本机骑行选项，Then 能只运行服务器；Given 正常/异常结束，When 当前会话释放，Then 本次系统配置和防火墙规则被还原且原配置保留。

## Design Notes

GUI 主线程只操作控件；配置和连接检查在后台线程；原服务在独立进程运行以保留信号处理和可停止性。服务子进程通过随机令牌认证的本机连接报告真正就绪并在父连接断开时退出。复用现有提权与恢复机制。服务器使用环境覆盖设置运行模式并写出预期服务配置；单机通过覆盖运行模式保留此前多人配置文件。

## Verification

执行 `python -m unittest discover -s tests -v` 和 `build.cmd`；运行 Tkinter 与打包 EXE 的无系统写入界面冒烟；检查归档内容。真实跨电脑骑行与受保护系统文件配置需要实际环境，交付记录必须区分模拟/隔离验证与真实联机。

结果：88 项单元测试通过；构建成功，真实图形 EXE 三模式开窗/关闭验证通过；复制 EXE 至临时中文路径后，实际服务进程的可信 HTTPS 状态/登录页、HTTP 资源、TCP 探测和父连接断开退出验证通过。系统配置与跨电脑完整骑行尚未实测，详见 `运行.md` 当前交付记录。
